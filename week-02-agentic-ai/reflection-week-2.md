# Reflection – Week 2

**Author: K. Sricharan**

Week 2 of my DevOps Micro Internship was an important learning experience because I started understanding how AI can become part of a real development workflow instead of being used only as a simple question-and-answer tool. During this week, I explored Claude Code, Skills, Subagents, MCP, Memory, Hooks, and Permissions. These topics helped me understand the idea of building a more structured and responsible AI-assisted development process.

One of the most useful topics for me was **Claude Code**. I learned how an AI coding assistant can work with a project, inspect files, understand project instructions, and help with development tasks. I also learned about the Agentic Loop: Gather, Act, and Verify. This changed the way I think about AI tools because the important part is not just asking AI to do something, but also checking what it did and verifying the result.

I also learned about **Subagents**. Instead of using one AI agent for every task, specialized subagents can be given different responsibilities. For example, a security auditor can focus on finding security issues, while another subagent can work on Terraform-related tasks. This showed me how a larger task can be divided into smaller responsibilities and handled in a more organized way.

Another important topic was **MCP (Model Context Protocol)**. I learned that MCP allows AI assistants to connect with external tools and services. Understanding MCP helped me see how AI can interact with systems such as GitHub and access useful information through connected tools. This made the concept of agentic AI much more practical for me.

I also explored **Memory, Hooks, and Permissions**. Memory can help an AI assistant remember useful project-specific instructions and facts. Hooks and permissions helped me understand that AI automation should have boundaries and safety controls. These topics made me realize that giving an AI more capabilities also means we need to control and verify those capabilities carefully.

I faced some challenges during this week, especially while working with the terminal, project folders, installations, configuration files, and Claude Code commands. Sometimes a command did not work because of a path, configuration, or environment issue. Initially, these problems were frustrating, but I learned to slow down, read the error message, and troubleshoot the problem step by step instead of immediately assuming that something was broken.

The biggest mindset change for me was understanding that **AI should be treated as a development partner, not as a replacement for understanding the work**. I still need to understand the commands, review the output, and verify the changes made by AI.

One habit I plan to implement is a simple **AI verification routine**: whenever I ask an AI agent to make a change, I will first understand the requested task, allow the agent to perform it, and then verify the result using commands, tests, or manual inspection. I believe this habit will help me become a more responsible and confident DevOps engineer.

Overall, Week 2 gave me practical exposure to agentic AI and showed me how tools such as Claude Code, Subagents, MCP, Memory, Hooks, and Permissions can work together. I am looking forward to applying these concepts to more real-world DevOps problems.
